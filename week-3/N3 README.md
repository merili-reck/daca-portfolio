# Nädal 3: SQL Joins -- UrbanStyle'i andmete uurimine

## Mida ma tegin
- Õppisin, kuidas JOIN-käskude abil tabelite ühisosasid leida ja tabeleid vajadusel ühendada.
- Õppisin iseseivalt algusest peale SQL-i süntaksit. Üritasin ühendada uusi käske juba õpitutega ja iga päev teadmisi kinnistada.
- Uurisin klienditabelit, kus pidin tuvastama mustreid kadunud klientide kohta. Jagasin leide meeskonnakaaslastega.

## Peamised õppetunnid
- SQL-i peab õppima nagu keelt, järjepidevalt harjutades. Sain eelmistes loengutes aru, mida tehti, kuid süntaks kipub ajas ununema.
- Ettekandeid tehes võiks rohkem tähelepanu pöörata visuaalile, mis võiks nädalast-nädalasse paraneda ja areneda.
